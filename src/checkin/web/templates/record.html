怎么录制

{{ icon('info') }}
  1. 选择或新建站点，点击 开始录制，容器内会启动 Chromium 并通过 noVNC 嵌入页面。
  2. 在远程桌面里手动登录，并完成一次签到（点签到按钮或打开签到页）。
  3. 点击 完成录制：保存 Cookie / localStorage 以及导航和 POST 步骤。
  4. 站点切换为 {{ mode_badge('recorded') }}，定时任务和「立即签到」会无头回放该流程。
